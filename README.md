\# **Restaurant Data Analysis Projec**t



\## Project Overview

This project focuses on analyzing restaurant data using Python and Jupyter Notebook to identify trends and insights related to restaurant ratings, pricing, cuisines, and customer preferences.



\## Objectives

\- Explore and clean restaurant datasets.

\- Analyze restaurant price range distribution.

\- Understand restaurant ratings and customer voting patterns.

\- Identify useful trends through data analysis and visualization.

\- Present insights using charts and graphs.



\## Tools \& Technologies

\- Python

\- Jupyter Notebook

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn



\## Project Files

\- `Internship project.ipynb` – Main restaurant data analysis notebook.

\- `Price Range Distribution plot .ipynb` – Notebook for price range visualization.

\- `Dataset.csv` – Dataset used for analysis.

\- `Data Analysis task.pdf` – Project task instructions.



\## Key Analysis Areas

\- Data exploration and preprocessing

\- Restaurant price range distribution

\- Ratings and customer votes

\- Data visualization and trend analysis



\## How to Run

1\. Clone or download this repository.

2\. Install the required Python libraries.

3\. Open Jupyter Notebook.

4\. Run the notebooks to explore the analysis.

pip install pandas numpy matplotlib seaborn jupyter
